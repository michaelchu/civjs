# Hexemplio browser package

This directory is generated from the pinned `reference/freeciv` submodule by
`npm run generate:hexemplio-tileset`. Do not hand-edit its manifest, source
PNG sheets, or standalone pixel sprites. Large standalone assets such as flags
are listed in the manifest but loaded by the client only when requested.
