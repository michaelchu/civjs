# Freeciv AI Porting Inventory

Behavioral parity target for the supported classic/default AI.

## Scope

This inventory tracks native CivJS behavior against
`reference/freeciv/ai/default`, `reference/freeciv/ai/{difficulty,handicaps,aitraits}.c`,
`reference/freeciv/common/aicore`, and `reference/freeciv/server/advisors`.
Server behavior required by those AI paths, such as identities, caravan
settlement, airlift, and barbarian creation, is included in the consuming row.

Status is deliberately short:

- **Implemented:** an authoritative runtime path and focused evidence exist.
- **Partial:** the runtime has related behavior but not the referenced decision
  model.
- **Missing:** no equivalent behavior is wired into AI turns.

The audit is behavioral rather than line-for-line. Utility headers and logging
wrappers are covered with their implementation files; they are not separate
porting deliverables.
